## 📖 Sobre o Projeto | About the Project

**PT:** O CRM Open Source B2B foi criado para ajudar empresas e desenvolvedores a gerenciarem seus clientes e parcerias de forma simples, rápida e sem os custos exorbitantes das plataformas fechadas. O foco é ser uma ferramenta poderosa, mas de fácil implementação.

**EN:** The Open Source B2B CRM was created to help companies and developers manage their clients and partnerships in a simple, fast way, without the exorbitant costs of closed platforms. The focus is to be a powerful, yet easy-to-implement tool.

## 🤝 Como Contribuir | How to Contribute

Contribuições são sempre bem-vindas! Se você é desenvolvedor e quer ajudar a construir o futuro dos CRMs open source:
1. Faça um Fork do projeto.
2. Crie uma Branch para sua feature (`git checkout -b feature/NovaFeature`).
3. Faça o Commit (`git commit -m 'Adicionando nova feature'`).
4. Faça o Push (`git push origin feature/NovaFeature`).
5. Abra um Pull Request.
